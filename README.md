# Gold Homes DMV

Source code for [goldhomesdmv.com](https://goldhomesdmv.com), built with React and Vite.

## Lead intake

The website's buyer and seller calls-to-action open the combined Gold Homes DMV consultation form. Form responses feed the Gold Homes DMV Lead Tracker.

## Deployment

The `main` branch is connected to the Gold Homes DMV project on Vercel. New commits to `main` trigger a production deployment.
